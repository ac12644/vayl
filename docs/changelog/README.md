# Changelog

What changed in each Vayl release, newest first. Upgrade notes are on each release page.

| Release              | Date        | Highlights                                                                                                             |
| -------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------- |
| **v0.9.1** (current) | 22 Oct 2026 | gpt-6 support, server instructions for MCP clients, clearer model errors |
| v0.9.0 | 22 Oct 2026 | Python 3.11 minimum; listed in the official MCP Registry |
| v0.8.0 | 21 Oct 2026 | FastMCP 4 and MCP SDK v2, Python client HTTP fix, clean client shutdown |
| v0.7.0 | 27 Sep 2026 | Tenant isolation for policies, the graph, decisions, receipts, audit and principals; audit fixes |
| v0.6.0 | 26 Sep 2026 | `approve` capability for gated changes, HTTP transport fix, embeddings follow `OPENAI_API_KEY`, strict on/off settings |
| v0.5.1               | 26 Sep 2026 | Atomic SQLite migrations, `VAYL_DECRYPT_CACHE`                                                                         |
| v0.5.0               | 26 Sep 2026 | Faster tool calls, versioned migrations, request IDs                                                                   |
| v0.4.0               | 26 Sep 2026 | Framework adapters, tenant partitioning, fail-closed erasure                                                           |
| v0.3.0               | 29 Jul 2026 | Standalone FastMCP                                                                                                     |
| v0.2.0               | 28 Jul 2026 | `vayl-demo`, Python and TypeScript clients, presets                                                                    |
| v0.1.0               | 27 Jul 2026 | Initial release                                                                                                        |

Vayl is open source (Apache-2.0). The complete history is in [CHANGELOG.md](https://github.com/ac12644/vayl/blob/main/CHANGELOG.md) and the [GitHub releases](https://github.com/ac12644/vayl/releases).
