# v0.9.0 — Python 3.11 and the MCP Registry

_22 October 2026_

## Removed

* **Python 3.10 is no longer supported.** Vayl now requires Python 3.11 or newer. Python 3.10 reaches end of life this month, and the MCP SDK's HTTP client has already stopped releasing for it.

## Added

* Vayl is in the official [MCP Registry](https://registry.modelcontextprotocol.io) as `io.github.ac12644/vayl`, so MCP clients and directories that read the registry can find and install it.

## Upgrading

On Python 3.11 or newer, nothing to do. On Python 3.10, `pip install vayl-mcp` keeps installing 0.8.0; move to Python 3.11 or newer to get 0.9.0.

[Full notes on GitHub](https://github.com/ac12644/vayl/releases/tag/v0.9.0)
