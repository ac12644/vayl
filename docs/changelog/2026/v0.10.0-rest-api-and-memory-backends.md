# v0.10.0 — REST API and memory backends

_22 October 2026_

## Added

* **REST routes for every tool.** `vayl-server` serves `POST /v1/tools/<name>` (the tool's arguments as a JSON object, `{"result": "..."}` back) and `GET /v1/tools`, behind the same authentication and checks as `/mcp`. Errors use status codes: `401`, `403` for a missing capability or scope, `404` for an unknown tool, `422` for bad arguments. See the [HTTP API reference](https://vayl.gitbook.io/vayl-docs/api-reference).
* **An API reference generated from the code.** One typed operation per tool, with the capability it needs and a real example. A test fails if the spec drifts from the tools.
* **Memory backends for Google ADK, LlamaIndex and AutoGen.** They plug into each framework's own memory, so what the user says is stored and the current facts reach the model before each turn. Install with `pip install 'vayl-mcp[adk]'`, `[llamaindex]` or `[autogen]`. See [Agent frameworks](https://vayl.gitbook.io/vayl-docs/documentation/integrations/agent-frameworks), which also covers Pydantic AI and Agno over MCP.
* **Setup pages** for VS Code, Windsurf, Zed, Cline, Continue, Codex CLI and Gemini CLI.

No action needed to upgrade.
