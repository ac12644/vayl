# v0.11.0 — Automatic mode for gated changes

_11 November 2026_

## Added

* **Automatic mode.** For each message that changes a gated slot, a second model reads the message and states those fields as they are now, without seeing what was proposed. A change applies only when that reading agrees with it. Otherwise it waits in `pending_changes` and the current value stands. If the model cannot be reached, nothing is decided. Set by `VAYL_ESCALATE_MODEL`; see [Configuration](https://vayl.gitbook.io/vayl-docs/documentation/reference/configuration).
* **Verdict pass.** With a slot schema, a second call per message checks each current fact in a declared slot against the message and catches stops and switches the first pass missed (`VAYL_VERDICT`).
* **Constraints in the slot schema.** Declare "at most N current items" of a list, such as one anticoagulant. Changes that would break a constraint become one linked proposal, approved or rejected whole.
* **`"confirm": "auto"` and `"confirm": "earned"`.** On `auto`, a clear change applies by itself and an uncertain one waits. On `earned`, a slot applies changes by itself only while the current model has a clean record on it.
* **Pasted or retrieved text only proposes.** A change from a `source` such as `pasted`, `web` or `email` is never applied directly to a declared slot (`VAYL_PROPOSE_ONLY_SOURCES`).

## Fixed

* **Medication changes from free text are safe on the clinical preset.** Holds, "continue" and negated changes never alter the record, a switch applies whole or not at all, and a hold linked to a bridge drug waits with it.
* An item that ended is removed from its list instead of being filed as history beside the current one.
* A reply cut off at the token limit raises instead of being parsed as complete.
* Long notes with text copied forward raise fewer repeat questions.

## Upgrading

Three defaults changed:

* **Medications on the clinical preset apply by themselves when the change is clear.** Set `VAYL_CONFIRM_MODE=review` to approve every change as before.
* **With a slot schema, storing a fact can take up to three model calls** instead of one. Set `VAYL_VERDICT=off` or `VAYL_ESCALATE_MODEL=off` to drop a call.
* **With `ANTHROPIC_API_KEY` set and a slot schema in use, automatic mode is on** and sends the message text to Anthropic, even when another provider does the extraction. Set `VAYL_ESCALATE_MODEL=off` to turn it off.

The high-stakes episode sets behind this release are agent-written and have not been reviewed by a domain expert. Vayl is not certified for clinical use.
