# v0.8.0 — FastMCP 4 and MCP SDK v2

_21 October 2026_

## Changed

* **FastMCP 4 and MCP Python SDK v2** (`fastmcp>=4.1,<5`, `mcp>=2.3,<3`). The server's tools and wire format are unchanged. Vayl used to exclude these versions, so it couldn't be installed next to tools that need them.
* The Python client's HTTP mode, `Vayl(url=…, api_key=…)`, uses the SDK v2 transport. It failed with an `ImportError` on SDK v2 before.
* GitHub Actions are updated to their latest releases, including CodeQL v4.

## Fixed

* The Python client shuts down completely, including after a failed connection. Before, it could leave a background thread with half-open connections, which crashed Python 3.10 on Linux at exit.
* A failed connection raises one readable `VaylError` naming the server and the cause, instead of a nested exception group.

## Upgrading from 0.7

* Nothing to do for servers or the stdio client.
* If your project pins `mcp<2` or `fastmcp<4`, stay on Vayl 0.7 until you can move.
* Python 3.10 still works. It reaches end of life in October 2026, and a later release will require Python 3.11.
