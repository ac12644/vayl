# v0.9.1 — gpt-6 and server instructions

_22 October 2026_

## Added

* **Vayl tells MCP clients when to use it.** The server sends MCP `instructions` when a client connects: call `remember` when the user states or changes a fact, `recall` before answering from what was said earlier, and `forget` for removals. In a live Claude Code test, "Remember for this project: our database is Postgres" went to a notes file without them and to Vayl with them. A `CLAUDE.md` rule is now optional.

## Fixed

* **gpt-6 models work.** `OPENAI_MODEL=gpt-6-luna` (or any gpt-6) was sent `temperature: 0` and `max_tokens`, which gpt-6 rejects, so every `remember` and `recall` failed. gpt-5 and later now get `max_completion_tokens` and the lowest reasoning effort the family accepts: `minimal` on gpt-5, `none` from gpt-6.
* **A rejected model call explains itself.** `health` shows the provider's status and message, for example `llm: FAIL (HTTP 401: Incorrect API key provided …)`. A tool that fails this way names the HTTP status and points to `health`, without showing the provider's text.

No action needed to upgrade.
